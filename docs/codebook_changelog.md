# Codebook changelog

Every change to `docs/codebook.md` gets an entry here. The version number must match the
heading in `codebook.md`, because it is recorded as `prompt_version` in every output line.

## v1
- First version: four categories (ENABLER, DISRUPTED, BENEFICIARY, LIMITED) applied in
  rule order, a top-three-driver materiality test, edge-case rules, and four output fields
  (`category`, `confidence`, `knows_company`, `rationale`).
